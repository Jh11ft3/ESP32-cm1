ESP32-DOS BLE Terminal Help

Connect: Click "Connect" and select "ESP32-DOS" from the Bluetooth device list.

Usage: Type DOS commands in the input box and press Enter to execute.

WiFi Setup:

  WIFI SCAN - Scan available networks

  WIFI <SSID> <password> - Connect to WiFi

  WEBCONFIG - Start web config portal (AP mode)

Download:

  WGET <url> - Download file from HTTP

BLE:

  BLE STATUS - Show BLE status

Note: Requires Chrome/Edge browser with Web Bluetooth support. Mobile Chrome on Android is supported.
